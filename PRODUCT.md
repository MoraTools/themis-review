# Themis Review

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Automation Anywhere A360 developers who review exported taskbots before use or handover.

## Product Purpose

Review Control Room export zip files locally. Show dependencies, code, findings, and scores so developers can find and correct problems.

## Positioning

The analysis runs in the browser. Uploaded code does not leave the browser. Themis is part of the Helios, Athena, and Themis tool family.

## Operating Context

Upload one or more A360 export zips. Use the map to inspect taskbots and their variables. Read the report, filter findings, and export the visible report with the browser's PDF print function. The rules page explains deductions and grade bands.

## Capabilities and Constraints

Vite, React, and TypeScript. English and Spanish interface. No backend or account is required. Analysis and scoring belong to `src/core`, which this theme work must not change. Theme and language preferences are local to this browser.

## Brand Commitments

Keep the Themis name, seven random upload phrases, dithered statue, credit, and gold upload rim. Use the approved One gold suite theme with softer contrast and both light and dark modes.

## Evidence on Hand

`README.md`, `docs/index.html`, existing UI and local test zips describe the product. The approved suite previews and the user's theme decisions define this change. No new claims or sample client data are needed.

## Product Principles

- Keep uploaded code local.
- Make findings traceable to taskbots and code.
- Keep score rules visible and consistent.
- Preserve task access on small screens and in either language.

## Accessibility & Inclusion

Follow browser theme and language unless the user selects an override. Provide visible keyboard focus, reduced-motion support, and readable contrast in both themes and print.
